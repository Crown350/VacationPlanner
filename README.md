# Corporate Vacation Planner

Система автоматизации учета и планирования отпусков для средних и крупных предприятий. Разработана для снижения нагрузки на HR-отдел и повышения прозрачности процесса согласования отпусков.

## Возможности

*   **Ролевая модель доступа:**
    *   **Сотрудник:** Просмотр баланса отпусков, подача заявок через календарь, отслеживание статусов.
    *   **Руководитель:** Дашборд с заявками подчиненных, инструменты согласования/отклонения с автоматическим пересчетом баланса.
    *   **HR/Администратор:** Полный реестр сотрудников, аналитические отчеты, управление оргструктурой.
*   **Учет бизнес-дней:** Автоматический расчет длительности отпуска с исключением выходных и праздников.
*   **Аналитика:** Визуализация загруженности отделов и статистика использования отпусков.
*   **Экспорт данных:** Генерация отчетов в формате Excel.

## Технологический стек

*   **Python 3.10+**
*   **GUI:** Tkinter (ttk) с кастомной темой оформления.
*   **Database:** SQLite (с возможностью миграции на PostgreSQL/MSSQL).
*   **Data Analysis:** Pandas, Matplotlib.
*   **Components:** `tkcalendar` для выбора дат.

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/vacation-planner.git
    cd vacation-planner
    ```

2.  **Создайте виртуальное окружение:**
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # Linux/macOS
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install pandas matplotlib tkcalendar openpyxl
    ```

4.  **Запустите приложение:**
    ```bash
    python main.py
    ```

## Демонстрационный доступ

При первом запуске база данных автоматически инициализируется следующими учетными записями:

| Роль | Логин | Пароль | Описание |
|------|-------|--------|----------|
| **HR (Admin)** | `admin` | `admin123` | Полный доступ к системе |
| **Руководитель** | `manager` | `manager123` | Согласование заявок отдела |
| **Сотрудник** | `user` | `user123` | Подача заявок |

## Безопасность

Пароли пользователей хранятся в базе данных в виде SHA-256 хешей с использованием соли. В производственной среде рекомендуется сменить соль в файле `database.py` или вынести её в переменную окружения `APP_SALT`.
